# Public Background Assets

Files in this folder are served directly by Vite from the site root.

The auth screens currently expect this file:

```text
auth-castle-sunset.png
```

Expected path:

```text
client/public/assets/backgrounds/auth-castle-sunset.png
```

CSS URL used by the app:

```text
/assets/backgrounds/auth-castle-sunset.png
```

Recommended export:

- Aspect ratio: `16:9`
- Desktop size: `1920x1080` or larger
- Format: `png`
- Keep the main subject near the center so `background-position: center center` works on mobile.
